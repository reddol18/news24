# 뉴스 스크랩 사이트

- (현재까지는) 프레시안, 경향, 한겨레, 오마이뉴스의 최신 기사를 30분에 한 번씩 수집해서 보여주고 있습니다.
- 이 레포지토리는 이 중에서 프런트 사이트를 구성하는 코드들의 집합니다.
  - https://news24.reddol18.pe.kr
- 아래와 같은 기술스택으로 구성되어 있습니다.
  - TypeScript 기반 next.js (SSG)
  - Tailwind CSS
- 참고로 백엔드는 다음과 같은 기술스택으로 구성되어 있습니다.
  - minio : 썸네일 image 저장용
  - nest.js + TypeOrm + postgres : 기사 정보 저장 및 조회용
  - python + prefect : 기사수집용

# 앞으로의 계획

- 가치있는 기사를 작성하고 있는 비주류 언론사 및 인터넷신문사의 기사도 수집할 예정입니다.
- 단순히 수집해서 링크를 제공하는 수준을 넘어서서, 기사를 큐레이팅하는 서비스로 확장할 예정입니다.
  - 비슷한 관점을 가지고 있는 기사들을 함께 소개하기
  - 차이점을 가지고 논쟁적인 주제를 다루는 기사들을 함께 소개하기
  - 특정 주제에 대해 실증적 논거와 자료를 제공하는 기사들을 함께 소개하기
